Install Android Studio



Setup Phone (for development)



* Enable Developer Mode (Phone)
* Settings -> About Phone
* Tap Build Number 7 times
* Enable: USB Debugging



Connect phone to PC via usb -> enable usb file tranfer if the phone defaults to charging phone only connection.



In the terminal, enter < adb devices >



Install ADB when prompted, make sure the phone is unlocked, you will get a notification on the phone to allow USB debugging, 

if successful you will see something like this in your terminal: R58N123ABC    device
